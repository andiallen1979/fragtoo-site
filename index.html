Fragtoo Linux & Community Overlay Registry

A binary-first Gentoo distribution engineered for Steam Deck (znver2) paired with an open, user-driven overlay directory. Install community overlays without waiting on central XML gatekeepers.

1. Bootstrap fragtoo-hub on Any Gentoo System

Because single ebuilds cannot be hosted directly in the official Gentoo tree without dev-channel review, use our bootstrap script to register the fragtoo repo and merge app-portage/fragtoo-hub in one step:

curl -fsSL https://fragtoo.com | sudo bash
Download Desktop Installer (.desktop)
  1. Configures /etc/portage/repos.conf/fragtoo.conf pointing to the Fragtoo Git overlay.
  2. Syncs the tree via emaint sync -r fragtoo and unmasks ~amd64 / ~arm64 for fragtoo-hub.
  3. Emerges app-portage/fragtoo-hub so you can run fragtoo-hub list and fragtoo-hub add <name>.
